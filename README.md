# TIME MANAGER

The idea behind this app is to have a simple time manager application (with my own rules for my personal use). You are free to download and use it if you want or to colaborate to improvements.

## Features Planned (v0):
- Start Timer and Stop TImer, linking the time to project
- Overview of Time Spent on Each Project
- Detailed Overview (with option to select by day)
- System Tray, Initialization on Boot

## Crates
- Iced.rs for the UI
- Tray for tray management
- Auto launch for initialization on boot

## Requirements (Development)
- libs: pango-devel, pkg-config, glib2
